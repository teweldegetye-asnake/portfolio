UNIVERSITY EMERGENCY ALERT SYSTEM

A mobile and web based system that allows students and university community to quickly report emergencies with thier location to adminstrators. This project focuses on providing emergency alert services for students, staff, and community members within a university campus. The system consists of a mobile application for users and a central monitoring system for security personnel to manage emergency incidents.

Technologies:

  • HTML
  • CSS
  • JavaScript
  • Firebase
  • Cordova

Main Features:

  • Emergency alert
  • GPS location
  • User authentication
  • Admin dashboard
  • Alert management
